# OS MENINO DA UMBRELLA — SITE BASE

## Como abrir
1. Extraia a pasta.
2. Abra `index.html` no navegador.

## Para usar localhost
Se tiver Python instalado:
- abra o terminal nesta pasta
- rode: `python -m http.server 5500`
- acesse: `http://localhost:5500`

## Onde editar
- `index.html` = textos, artistas, links e estrutura.
- `style.css` = cores, fontes, tamanhos, espaçamentos e responsividade.
- `script.js` = menu mobile e animações.

## Imagens
Os blocos dos artistas estão com fundos de demonstração. Para colocar fotos:
1. crie uma pasta `images`
2. coloque as fotos nela
3. altere o CSS de cada `.image-1`, `.image-2` etc. para `background-image: url("images/nome.jpg");`

O conteúdo é uma base editável; os nomes, links e textos marcados como exemplo devem ser substituídos pelos dados oficiais.
